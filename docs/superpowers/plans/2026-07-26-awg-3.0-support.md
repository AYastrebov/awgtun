# AWG 3.0 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add AmneziaWG 3.0 support (header protection, content padding, randomized timings) to this boringtun fork, at parity with amneziawg-go @ `9f5d948`.

**Architecture:** A new `Amnezia3Config` in `boringtun/src/amnezia.rs` reuses all 2.0 building blocks and adds a ChaCha20 header-protection key, a content-padding range, timing ranges, and an MTU. Header protection is applied as an in-place transform at `Tunn`'s send/receive boundaries; the Noise core is untouched. `Tunn::new_with_amnezia3` is the single real constructor; `new`/`new_with_amnezia` delegate to it.

**Tech Stack:** Rust (edition 2018), boringtun, RustCrypto `chacha20` 0.9, amneziawg-go as reference (clone at `/tmp/amneziawg-go`).

**Spec:** `docs/superpowers/specs/2026-07-26-awg-3.0-support-design.md`

**Progress:** All tasks are complete. Four fixes landed alongside them after a
review against amneziawg-go `d57d98d`: `0bde1ea` (full-width range overflow),
`875d8d3` (allocation-free header-protected receive), `e1b4116` (data-sent
classified by wire size) and a type-mask derivation fix, plus an FFI fix for
zeroed `amnezia_config` structs.

Deviations from the plan as written, all recorded in the spec:

- Task 5 decrypts into stack buffers instead of a per-packet `Vec`.
- Task 6's data-sent rule is wire-size based and already landed with the
  keepalive-padding fix, so the step was a no-op.
- Task 7 re-rolls the retransmit timeout on every initiation (including
  retries) rather than only on new handshakes, matching
  `timersHandshakeInitiated`. `DetRng` was not promoted out of `#[cfg(test)]`;
  `timers.rs` uses a local deterministic RNG instead, keeping the public API
  unchanged.
- Task 8 embeds `amnezia_config` in `amnezia3_config` as a `base` field rather
  than duplicating the 2.0 fields, and treats an all-zero header protection key
  as "off".

// ---------------------------------------------------------------------------
// AWG 3.0 — generic ranges and timing configuration
// ---------------------------------------------------------------------------

/// Default outer MTU used for content-padding clamping (matches amneziawg-go's
/// default device MTU).
pub const AWG3_DEFAULT_MTU: u32 = 1420;

/// Minimum S1-S4 padding when header protection is enabled: the ChaCha20
/// nonce is read from the first 12 bytes of the random padding prefix.
pub const HEADER_PROTECTION_MIN_PADDING: u8 = 12;

/// Inclusive `u32` range used by AWG 3.0 content padding and timing
/// parameters. A fully-zero range means "unset" (fall back to the WireGuard
/// default), matching amneziawg-go's `UintRange`.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct U32Range {
    pub lo: u32,
    pub hi: u32,
}

impl U32Range {
    pub const fn zero() -> Self {
        U32Range { lo: 0, hi: 0 }
    }

    pub const fn single(value: u32) -> Self {
        U32Range {
            lo: value,
            hi: value,
        }
    }

    pub fn new(lo: u32, hi: u32) -> Result<Self, ConfigError> {
        if hi < lo {
            return Err(ConfigError::InvalidRange {
                value: format!("{}-{}", lo, hi),
                reason: "range end is smaller than start",
            });
        }
        Ok(U32Range { lo, hi })
    }

    /// Parse `"a"` or `"a-b"` (decimal, inclusive).
    pub fn parse(input: &str) -> Result<Self, ConfigError> {
        let input = input.trim();
        if input.is_empty() {
            return Err(ConfigError::InvalidRange {
                value: input.to_owned(),
                reason: "empty value",
            });
        }

        let mut parts = input.split('-');
        let lo = parse_range_part(input, parts.next())?;
        let hi = match parts.next() {
            Some(part) => parse_range_part(input, Some(part))?,
            None => lo,
        };
        if parts.next().is_some() {
            return Err(ConfigError::InvalidRange {
                value: input.to_owned(),
                reason: "expected `value` or `start-end`",
            });
        }

        U32Range::new(lo, hi)
    }

    /// A fully-zero range means "unset" — callers fall back to defaults.
    pub fn is_zero(&self) -> bool {
        self.lo == 0 && self.hi == 0
    }

    /// Pick a random value from `[lo, hi]` (inclusive).
    pub fn generate(&self, rng: &mut dyn RandomSource) -> u32 {
        rng.gen_range_u32(self.lo, self.hi)
    }

    /// Random pick, or `default` when the range is unset.
    pub fn pick_or(&self, rng: &mut dyn RandomSource, default: u32) -> u32 {
        if self.is_zero() {
            default
        } else {
            self.generate(rng)
        }
    }

    /// Range lower bound, or `default` when unset.
    pub fn lo_or(&self, default: u32) -> u32 {
        if self.is_zero() {
            default
        } else {
            self.lo
        }
    }

    /// Range upper bound, or `default` when unset.
    pub fn hi_or(&self, default: u32) -> u32 {
        if self.is_zero() {
            default
        } else {
            self.hi
        }
    }
}

fn parse_range_part(input: &str, part: Option<&str>) -> Result<u32, ConfigError> {
    let part = part.unwrap_or_default().trim();
    if part.is_empty() {
        return Err(ConfigError::InvalidRange {
            value: input.to_owned(),
            reason: "empty range bound",
        });
    }
    part.parse::<u32>().map_err(|_| ConfigError::InvalidRange {
        value: input.to_owned(),
        reason: "expected decimal digits",
    })
}

/// AWG 3.0 randomized timing parameters (all ranges, seconds except
/// `max_handshake_attempts` which is a count). Unset (zero) ranges fall back
/// to the classic WireGuard constants, preserving standard behavior.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct TimingRanges {
    pub rekey_after_time: U32Range,
    pub rekey_timeout: U32Range,
    pub reject_after_time: U32Range,
    pub keepalive_timeout: U32Range,
    pub max_handshake_attempts: U32Range,
    pub persistent_keepalive: U32Range,
}

impl TimingRanges {
    pub fn is_zero(&self) -> bool {
        self.rekey_after_time.is_zero()
            && self.rekey_timeout.is_zero()
            && self.reject_after_time.is_zero()
            && self.keepalive_timeout.is_zero()
            && self.max_handshake_attempts.is_zero()
            && self.persistent_keepalive.is_zero()
    }
}
```

// ---------------------------------------------------------------------------
// AWG 3.0 — header protection (ChaCha20 over low-entropy header fields)
// ---------------------------------------------------------------------------

pub const HEADER_PROTECTION_KEY_SIZE: usize = 32;
pub const HEADER_PROTECTION_NONCE_SIZE: usize = 12;

/// AWG 3.0 header protection key. Applies raw (unauthenticated) ChaCha20 to
/// the WireGuard message that follows the random padding prefix; the first
/// 12 bytes of that prefix are the nonce. Mirrors amneziawg-go's
/// `Device.HeaderProtectionCipher`.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct HeaderProtection {
    key: [u8; HEADER_PROTECTION_KEY_SIZE],
}

impl HeaderProtection {
    pub fn new(key: [u8; HEADER_PROTECTION_KEY_SIZE]) -> Self {
        HeaderProtection { key }
    }

    /// XOR `message` in place with the ChaCha20 keystream (block counter 0).
    /// `prefix` is the random crypto padding preceding the message; its first
    /// 12 bytes are the nonce.
    ///
    /// # Panics
    /// Panics if `prefix` is shorter than the nonce size. Config validation
    /// (S1-S4 >= 12) guarantees this cannot happen for real packets.
    pub fn apply(&self, prefix: &[u8], message: &mut [u8]) {
        use chacha20::cipher::{KeyIvInit, StreamCipher};

        let nonce: &[u8; HEADER_PROTECTION_NONCE_SIZE] = prefix
            [..HEADER_PROTECTION_NONCE_SIZE]
            .try_into()
            .expect("header protection requires at least 12 bytes of padding prefix");
        let mut cipher = chacha20::ChaCha20::new((&self.key).into(), nonce.into());
        cipher.apply_keystream(message);
    }

    /// Decrypt a 4-byte message-type candidate (keystream bytes 0..4).
    pub fn peek_type(&self, prefix: &[u8], type_bytes: [u8; 4]) -> u32 {
        let mut buf = type_bytes;
        self.apply(prefix, &mut buf);
        u32::from_le_bytes(buf)
    }
}
```

        self.junk.validate()?;
        self.paddings.validate()?;
        self.init_packets.validate()?;

        if self.junk == JunkConfig::disabled()
            && self.paddings == PaddingConfig::default()
            && self.headers == HeaderConfig::wireguard_compatible()
            && self.init_packets == InitPacketConfig::default()
        {
            self.headers.validate_wireguard_compatible()?;
        } else {
            self.headers.validate()?;
        }

            for (field, value) in [
                (PaddingKind::Init, self.paddings.s1),

                        field,
                        value,
                        min: HEADER_PROTECTION_MIN_PADDING,

            }
        }

        Ok(())

        let current = self.current;
        if let Some(ref session) = self.sessions[current % N_SESSIONS] {

            let packet = self.format_transport_packet(session, src, dst);

        session: &session::Session,
        src: &[u8],

            hp.apply(&dst[..s4], &mut dst[s4..s4 + TRANSPORT_HEADER_SZ]);
        }
        &mut dst[..s4 + packet_len]
    }

    /// Determine the padding length for an incoming packet by trying each
    /// message type's padding + expected size, then validating the header at
    /// the padding offset. With AWG 3.0 header protection enabled, the
    /// 4 type bytes are decrypted before the range check.
    ///
    /// Returns `Some((padding, protected_len))` where `protected_len` is the
    /// number of bytes after the padding covered by header protection (the
    /// full message for handshake types, the 16-byte header for transport),
    /// or `None` if no match.
    fn determine_padding(&self, src: &[u8]) -> Option<(usize, usize)> {
        let checks: [(usize, &crate::amnezia::HeaderRange, usize, bool); 4] = [
            (
                self.padding_config.s1 as usize,
                &self.header_config.init,
                HANDSHAKE_INIT_SZ,
                true,
            ),
            (
                self.padding_config.s2 as usize,
                &self.header_config.response,
                HANDSHAKE_RESP_SZ,
                true,
            ),
            (
                self.padding_config.s3 as usize,
                &self.header_config.cookie,
                COOKIE_REPLY_SZ,
                true,
            ),
            (
                self.padding_config.s4 as usize,
                &self.header_config.transport,
                DATA_OVERHEAD_SZ,
                false,
            ),
        ];

        for &(padding, header_range, expected_size, exact) in &checks {
            let size_ok = if exact {
                src.len() == padding + expected_size
            } else {
                src.len() >= padding + expected_size
            };

            if size_ok && padding + 4 <= src.len() {
                let type_bytes: [u8; 4] = src[padding..padding + 4]
                    .try_into()
                    .expect("bounds checked: padding + 4 <= src.len()");
                let header = match self.header_protection {
                    Some(hp) => hp.peek_type(&src[..padding], type_bytes),
                    None => u32::from_le_bytes(type_bytes),
                };
                if header_range.contains(header) {
                    let protected_len = if exact {
                        expected_size
                    } else {
                        TRANSPORT_HEADER_SZ
                    };
                    return Some((padding, protected_len));
                }
            }
        }
        None
    }

    /// range, clamped to the remaining space in the last MTU segment
    /// (mirrors amneziawg-go's `randomPaddingAddition`; boringtun never pads
    /// to a multiple of 16, so the addition applies as-is).
    fn content_padding_addition(&self, packet_size: usize) -> usize {

        let mut add = range.generate(&mut OsRandom) as usize;

            }
        }

    }

/// Returns NULL on failure (invalid keys or invalid amnezia config).
/// Keys must be valid base64 encoded 32-byte keys.
#[no_mangle]

    static_private: *const c_char,
    server_static_public: *const c_char,
    preshared_key: *const c_char,
    keep_alive: u16,
    index: u32,
    config: *const amnezia3_config,

        return new_tunnel(static_private, server_static_public, preshared_key, keep_alive, index);
    }

    let base = match amnezia2_from_c(&cfg.base) {
        Ok(b) => b,
        Err(_) => return null_mut(),

    } else {

        let mut key = [0u8; HEADER_PROTECTION_KEY_SIZE];
        key.copy_from_slice(bytes);
        Some(key)
    };

        cfg.content_padding_min,
        cfg.content_padding_max,
    ) {
        Ok(range) if range.is_zero() => None,
        Ok(range) => Some(range),
        Err(_) => return null_mut(),
    };

    let timing_ranges = TimingRanges {
        rekey_after_time: match u32_range_from_c(cfg.rekey_after_time_min, cfg.rekey_after_time_max) { Ok(r) => r, Err(_) => return null_mut() },
        rekey_timeout: match u32_range_from_c(cfg.rekey_timeout_min, cfg.rekey_timeout_max) { Ok(r) => r, Err(_) => return null_mut() },
        reject_after_time: match u32_range_from_c(cfg.reject_after_time_min, cfg.reject_after_time_max) { Ok(r) => r, Err(_) => return null_mut() },
        keepalive_timeout: match u32_range_from_c(cfg.keepalive_timeout_min, cfg.keepalive_timeout_max) { Ok(r) => r, Err(_) => return null_mut() },
        max_handshake_attempts: match u32_range_from_c(cfg.max_handshake_attempts_min, cfg.max_handshake_attempts_max) { Ok(r) => r, Err(_) => return null_mut() },
        persistent_keepalive: match u32_range_from_c(cfg.persistent_keepalive_min, cfg.persistent_keepalive_max) { Ok(r) => r, Err(_) => return null_mut() },
    };

    let amnezia = Amnezia3Config {
        junk: base.junk,
        paddings: base.paddings,
        headers: base.headers,
        init_packets: base.init_packets,
        header_protection_key,
        content_padding_addition,
        timing_ranges,
        mtu: if cfg.mtu == 0 { AWG3_DEFAULT_MTU } else { cfg.mtu },
    };

    let c_str = CStr::from_ptr(static_private);
    let static_private = match c_str.to_str() {
        Err(_) => return ptr::null_mut(),
        Ok(string) => string,
    };

    let c_str = CStr::from_ptr(server_static_public);
    let server_static_public = match c_str.to_str() {
        Err(_) => return ptr::null_mut(),
        Ok(string) => string,

            if let Ok(key) = string.parse::<KeyBytes>() {
                Some(key.0)
            } else {
                return null_mut();
            }
        } else {
            return null_mut();
        }
    };

    let private_key = match static_private.parse::<KeyBytes>() {
        Err(_) => return ptr::null_mut(),
        Ok(key) => StaticSecret::from(key.0),
    };

        Err(_) => return ptr::null_mut(),
        Ok(key) => PublicKey::from(key.0),

        panic::set_hook(Box::new(move |_| {
            raise(SIGSEGV);
        }));
    });

## Spec deviation notes (approved design vs. discoveries during planning)

1. **S4 on keepalives**: the spec describes the fork's existing "S4 skipped for keepalives" behavior; upstream fixed this in f4f4c99 (receiver expects S4 on all transport packets, and header protection needs the prefix for the nonce). The plan changes the fork to match upstream.
2. **No pad-to-16**: boringtun never padded transport content (`session.rs` TODO), so CPA is purely additive — the spec's "replaces pad-to-16" is a no-op here.
3. **No jitter**: boringtun's retransmit check has no jitter (the spec mentioned "existing jitter" from the Go analysis); none is added.
4. **`max_handshake_attempts`**: boringtun gives up on time (`REKEY_ATTEMPT_TIME`), not count; the plan maps the range onto `attempts × rekey_timeout` picked per handshake initiation.
5. **Silent drop**: `validate_decapsulated_packet` changes non-IP payloads from `Err(InvalidPacket)` to `Done` for Go parity (required for CPA keepalives).
